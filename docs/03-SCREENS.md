# 03. 화면 설계

## 라우트 맵

```
/                       랜딩 (비로그인) → 로그인 시 /home 리다이렉트
/login                  로그인 (이메일 + 비밀번호)
/signup                 가입 (이름 · 이메일 · 비밀번호)
/auth/callback          이메일 인증 / OAuth 콜백 처리
/home                   오늘 할 일 + 내 식물 그리드
/plants                 내 식물 전체 목록 (필터/정렬)
/plants/new             식물 등록
/plants/:id             식물 상세 (히어로 + 타임라인 + 케어 정보)
/plants/:id/edit        식물 수정
/plants/:id/compare     Before/After 비교              [v1.1]
/entries/new            일지 작성 (?plantId= 쿼리)
/entries/:id            일지 상세 (사진 갤러리 + AI 카드)
/entries/:id/edit       일지 수정
/calendar               월간 캘린더
/archive                떠나보낸 식물                    [v1.1]
/settings               프로필 / 알림 / 테마 / 내보내기 / 탈퇴
*                       404
```

## 브레이크포인트

| 이름 | 범위 | 레이아웃 |
|---|---|---|
| `mobile` | < 768px | 하단 탭 4개 + FAB, 단일 컬럼 |
| `tablet` | 768 ~ 1279px | 좌측 아이콘 레일, 2컬럼 그리드 |
| `desktop` | ≥ 1280px | 좌측 사이드바 + 콘텐츠 + 우측 상세 패널 |

## 3. 일지 작성 `/entries/new` ★ 가장 중요

목표: **사진 선택 → 태그 탭 → 저장, 3탭.**

```
┌─────────────────────────┐
│ ✕  일지 쓰기      [저장] │  ← 저장은 항상 우상단 고정
├─────────────────────────┤
│                         │
│  어떤 식물인가요?        │
│ ┌─────────────────────┐ │
│ │ 🪴 몬스테라       ▾ │ │  ← 쿼리로 넘어오면 미리 선택됨
│ └─────────────────────┘ │
│                         │
│  사진                   │
│ ┌────┐┌────┐┌────┐     │
│ │[1] ││[2] ││ +  │     │  ← 최대 5장, 드래그 정렬
│ └────┘└────┘└────┘     │
│                         │
│ ┌─────────────────────┐ │
│ │ 📅 2026-09-14 15:22 │ │  ← EXIF 자동 추출
│ │    ✏️ 수정           │ │
│ │ ⓘ 사진에서 가져왔어요 │ │  ← 출처 명시 (중요)
│ └─────────────────────┘ │
│                         │
│  무엇을 했나요? (복수)    │
│ ┌────┐┌────┐┌────┐     │
│ │💧물││🪴분││🌿비│     │  ← 선택 시 채워짐
│ └────┘└────┘└────┘     │
│ ┌────┐┌────┐┌────┐     │
│ │✂️가││☀️이││👀관│     │
│ └────┘└────┘└────┘     │
│                         │
│  메모 (선택)             │
│ ┌─────────────────────┐ │
│ │ 새 잎이 났다!        │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

### EXIF 날짜 출처별 문구

| `date_source` | 표시 문구 |
|---|---|
| `exif` | ⓘ 사진에서 촬영일을 가져왔어요 |
| `file_mtime` | ⚠️ 사진에 날짜 정보가 없어 파일 날짜를 썼어요. 맞나요? |
| `manual` | (문구 없음) |

**자동 추출이 실패해도 절대 막히지 않는다.** 날짜 입력칸은 항상 보이고 항상 수정 가능하다.

## 6. 빈 상태 / 로딩 / 에러

| 상황 | 처리 |
|---|---|
| 식물 0개 | 일러스트 + "첫 식물을 등록해보세요" + 단일 CTA |
| 일지 0개 | "아직 기록이 없어요. 사진 한 장으로 시작해보세요" |
| 로딩 | **스켈레톤** (스피너 금지 — 레이아웃 점프 발생) |
| 네트워크 오류 | "연결이 불안정해요" + 재시도 버튼 |
| 업로드 실패 | 로컬 큐에 보관 + "나중에 다시 시도" 배너 |
| AI 분석 대기 | 스켈레톤 + "사진을 살펴보는 중..." |
| AI 분석 실패 | "지금은 답하기 어려워요" + 재시도 (쿼터 미차감) |
| AI 쿼터 초과 | "오늘의 질문을 모두 썼어요. 내일 다시 만나요" |

## 접근성 기준

- 모든 이미지에 `alt` (식물 애칭 + 촬영일 자동 생성)
- 활동 태그는 **이모지 + 텍스트 라벨** 동시 제공 (이모지만으로 정보 전달 금지)
- 대비비 4.5:1 이상 (AI severity 색상 포함)
- 키보드만으로 일지 작성 완주 가능
- `prefers-reduced-motion` 존중 (타임라인 애니메이션 비활성)
- 터치 타겟 최소 44×44px
