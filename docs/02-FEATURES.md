# 02. 기능 기획안

## MVP (v1.0) — 여기까지 만들고 출시

| # | 기능 | 상세 | 완료 기준 |
|---|---|---|---|
| **F1** | 로그인 | **이메일 + 비밀번호** (구현 완료). 소셜 로그인(Google / Apple / Kakao)은 추후 | 가입·메일 인증·재로그인 성공 |
| **F2** | 내 식물 등록 | 애칭(필수), 종류, 입양일, 장소, 대표 사진, 물주기 주기 | 등록 → 홈 그리드에 즉시 반영 |
| **F3** | 일지 작성 | 사진 1~10장 + 메모 + 활동 태그 | 사진 선택부터 저장까지 3탭 이내 |
| **F4** | EXIF 촬영일시 자동 추출 | 사진에서 날짜 추출 → 자동 입력. 출처 표시 + 수정 가능 | EXIF 有/無/HEIC/대용량 4케이스 통과 |
| **F5** | AI 상태 진단 | **테스트 버전: 질문 문구 복사 → 사용자가 웹 AI(ChatGPT/Claude)에 직접 질문.** API 호출 비용 0 | 문구 복사 + 사진 저장으로 답을 받을 수 있음 |
| **F6** | 성장 타임라인 | 식물별 일지 시간순 세로 타임라인 (사진 중심) | 무한스크롤, 50건까지 60fps 유지 |
| **F7** | 물주기 관리 | 주기 설정 → 홈에 "오늘 물 줄 아이" 배지 | D-day 계산 정확, 물주기 기록 시 리셋 |
| **F8** | 반응형 웹 | 모바일 / 태블릿 / PC | 3개 뷰포트에서 가로 스크롤 없음 |

### 활동 태그 (고정 7종)

```
💧 물주기    🪴 분갈이    🌿 비료    ✂️ 가지치기
☀️ 자리이동   👀 관찰만    ✍️ 기타
```

태그는 **DB enum으로 고정**한다. 사용자 커스텀 태그는 MVP에서 제외 —
자유 입력을 허용하면 통계·필터를 만들 수 없다.

## v1.1 — 재방문을 만드는 기능

| 기능 | 왜 |
|---|---|
| **소셜 로그인 (Google / Kakao)** | 대시보드 설정과 카카오 개발자 앱 등록이 필요해 MVP에서는 이메일로 시작. Apple은 연 $99 계정이 필요하므로 그 뒤 |
| **비밀번호 재설정** | 이메일 로그인을 쓰는 이상 언젠가 필요하다. `resetPasswordForEmail` 한 줄 + 재설정 화면 |
| **Before/After 비교 슬라이더** | 성장 실감이 재방문의 핵심 동기. 두 사진을 좌우 드래그로 비교 |
| **PWA 설치 + 웹 푸시** | 물주기 알림. iOS는 홈화면 추가 시에만 동작 (16.4+) |
| **성장 타임랩스** | 일지 사진을 순서대로 이어붙인 공유용 GIF/MP4 |
| **식물 카드 공유** | OG 이미지 생성 → 카톡/인스타 공유. 자연 유입 채널 |
| **통계** | 이번 달 물준 횟수, 최장 동행 식물, 활동 히트맵 |
| **아카이브** | 떠나보낸 식물도 기록은 남김 (soft delete 활용) |

## 의도적으로 안 만드는 것 (그리고 이유)

| 제외 | 이유 |
|---|---|
| 팔로우 / 좋아요 소셜 그래프 | MVP에 넣으면 빈 피드만 보인다. 콘텐츠가 쌓인 뒤 |
| 다국어 | 한국어만. i18n 구조만 열어두고 번역은 나중 |
| 사용자 커스텀 활동 태그 | 통계·필터 불가능해짐 |
| 식물 도감 / 백과사전 | 콘텐츠 제작 비용이 앱 개발보다 큼. AI가 대체 |
| 여러 사용자 공동 관리 | 권한 모델이 복잡해짐. 개인 앱으로 시작 |

## AI 실행 방식: 버튼 vs 자동 (확정: **버튼**)

### 판단 근거

| 방식 | 월 호출 수 (MAU 100 가정) | 문제 |
|---|---|---|
| 자동 (일지 저장마다) | ~9,000회 | 사용자가 원하지 않은 분석에도 비용 발생. 메모만 남기려는 기록도 분석 |
| **버튼 (물어보기)** | **~1,500회** | 발견성이 낮음 → UI로 해결 |

**버튼 방식이 비용을 1/6로 줄인다.** 전원 무료 정책에서는 이게 유일하게 지속 가능하다.

### 발견성 문제를 UI로 해결하는 방법

1. 일지 저장 직후 **결과 화면에 눈에 띄는 카드**로 배치
   ```
   ┌──────────────────────────────┐
   │ 🤖 이 사진, AI에게 물어볼까요?  │
   │                               │
   │  잎 상태나 이상 증상을 봐드려요  │
   │                               │
   │        [ 물어보기 ]            │
   │  오늘 5번 중 5번 남음          │
   └──────────────────────────────┘
   ```
2. **남은 횟수를 항상 표시** — 무료지만 유한하다는 인식 → 아껴 쓰되 있다는 걸 기억함
3. 이미 분석한 사진은 결과를 캐시 → 같은 사진 재분석 시 비용 0 (명시적 "다시 분석" 버튼만 새 호출)

상세 파이프라인은 [08-AI-PIPELINE.md](./08-AI-PIPELINE.md).

## 사용자 플로우 (핵심 3개)

### 1. 첫 사용
```
랜딩 → 소셜 로그인 → 식물 등록(애칭+사진) → 홈
                              ↓
                    "첫 일지를 남겨보세요" CTA
```

### 2. 일상 기록 (가장 중요, 3탭 목표)
```
FAB(+) → 사진 선택 → [EXIF 날짜 자동 입력] → 활동 태그 탭 → 저장
                                                              ↓
                                              "AI에게 물어볼까요?" 카드
```

### 3. 문제 발견
```
식물 상세 → 이상한 사진 발견 → 일지 상세 → [AI에게 물어보기]
                                              ↓
                              관찰 / 의심 증상 / 권장 조치 카드
                                              ↓
                                        👍 / 👎 피드백
```
