# 11. 비용 분석

## 질문: Supabase 안 쓰고 직접 서버 개발해서 배포하면 비용이 드는가?

**결론부터: 든다. 그리고 돈보다 시간이 훨씬 더 든다.**

---

## A. 직접 서버 구축 시 (Node/Nest + Postgres + S3)

### 월 현금 비용

| 항목 | 선택지 | 월 비용 |
|---|---|---|
| **컴퓨트** | Railway / Render / Fly.io Hobby | $5 ~ $10 |
| | AWS EC2 t4g.small | 약 $12 |
| **DB** | Neon / Supabase Postgres만 (무료 티어) | $0 |
| | Railway Postgres | 약 $5 |
| | AWS RDS db.t4g.micro | $12 ~ $15 |
| **오브젝트 스토리지** | **Cloudflare R2** (10GB 기준) | 약 $0.15 |
| | AWS S3 (10GB + 전송 50GB) | 약 $4.7 |
| **도메인** | .com / .app | 약 $1.5 |
| **합계 (최소 구성)** | | **$7 ~ $12 (약 1~1.7만원)** |
| **합계 (AWS 정석 구성)** | | **$30 ~ $35 (약 4~5만원)** |

> **R2를 권하는 이유**: 이미지 서비스는 **전송량(egress)이 진짜 비용**이다.
> S3는 egress $0.09/GB를 받지만 **R2는 egress가 무료**다.
> 사진 앱에서 이 차이는 사용자가 늘수록 커진다.

### 숨은 비용 — 이게 진짜다

직접 만들면 아래를 전부 **직접 짜고, 직접 유지보수**해야 한다.

| 항목 | 직접 구현 시 예상 공수 |
|---|---|
| OAuth 3종(Google/Apple/Kakao) + 토큰 갱신 + 세션 관리 | 5~8일 |
| 파일 업로드 (presigned URL, 검증, 정리) | 2~3일 |
| 모든 엔드포인트에 권한 체크 (RLS가 공짜로 해주던 것) | 3~5일 |
| DB 마이그레이션 체계 | 1~2일 |
| 백업 / 복구 절차 | 1~2일 |
| 모니터링 / 로깅 / 알림 | 2~3일 |
| 실시간 업데이트 (WebSocket 서버) | 2~3일 |
| 배포 파이프라인 (CI/CD, 무중단) | 2~3일 |
| **합계** | **약 3~5주** |

그리고 이건 **1회성이 아니다.** 보안 패치, 의존성 업데이트, 장애 대응이 계속 따라온다.

**MVP 개발 기간이 6주인데 인프라에 3~5주를 쓰는 건 말이 안 된다.**

## B. Supabase 사용 시

### Free 티어로 MVP는 충분하다

| 항목 | Free 티어 (대략) | MVP에 충분한가 |
|---|---|---|
| Database | 500MB | ✅ 일지 10만 건 이상 가능 (텍스트는 가볍다) |
| Storage | 1GB | ⚠️ 사진 300KB 기준 **약 3,300장** — 초기엔 충분, 성장하면 부족 |
| 대역폭 | 5GB/월 | ⚠️ 여기가 먼저 한계에 닿는다 |
| 월 활성 유저 | 50,000 | ✅ 차고 넘침 |
| Edge Function 호출 | 50만/월 | ✅ AI 호출이 월 2만 건이어도 여유 |

> ⚠️ **수치는 변동됩니다.** 실제 값은 [supabase.com/pricing](https://supabase.com/pricing)에서 직접 확인하세요.

### ⚠️ Free 티어의 함정 하나

**7일간 활동이 없으면 프로젝트가 일시정지(pause)된다.**
개발 중 잠깐 쉬었다가 돌아오면 수동으로 복구해야 한다. 데이터는 유지되지만 당황할 수 있다.
출시 후 실사용자가 있으면 문제되지 않는다.

### Pro 티어 ($25/월, 약 3.5만원)

넘어가야 하는 시점:
- Storage 1GB 초과 (사진 약 3,300장 = 유저 100명이 각 33장)
- 대역폭 5GB/월 초과 (이게 보통 먼저 온다)
- 프로젝트 일시정지가 곤란해질 때 (= 실사용자 생겼을 때)

**Pro는 8GB DB / 100GB Storage / 250GB 대역폭** 수준으로 올라간다.

## C. 정면 비교

| | 직접 구축 | Supabase |
|---|---|---|
| 초기 개발 공수 | +3~5주 | 0 |
| 월 비용 (MVP) | 1~5만원 | **0원** |
| 월 비용 (MAU 1,000) | 3~8만원 | 3.5만원 (Pro) |
| 인증 구현 | 직접 | 내장 |
| 권한 관리 | 엔드포인트마다 직접 | RLS (선언적) |
| 실시간 | WebSocket 서버 직접 | 내장 |
| 운영 부담 | 계속 | 거의 없음 |
| 자유도 | 높음 | 제약 있음 |
| 벤더 종속 | 없음 | **있음** |

## 결론

**MVP는 Supabase Free로 시작한다. 월 0원.**

근거:
1. 3~5주의 개발 공수를 절약한다 = MVP 기간의 절반 이상
2. 사용자가 없는 단계에서 인프라 비용은 순수 낭비다
3. 아직 만들 가치가 있는 앱인지도 검증되지 않았다

**직접 서버를 고려해야 할 시점** (지금이 아니다):
- Supabase Pro로도 감당 안 되는 규모
- RLS로 표현할 수 없는 복잡한 권한 모델이 필요해질 때
- 규제로 인해 데이터 위치를 직접 통제해야 할 때

## 벤더 종속(lock-in) 현실적 평가

나중에 벗어나야 한다면 얼마나 어려운가?

| 구성요소 | 이전 난이도 | 비고 |
|---|---|---|
| **Postgres 데이터** | 🟢 쉬움 | `pg_dump` → 어떤 Postgres로든. 표준 SQL |
| **Storage 파일** | 🟢 쉬움 | S3 호환 API. rclone으로 복사 |
| **Auth** | 🔴 어려움 | 유저 테이블은 옮겨도 **비밀번호 해시/OAuth 연결은 재구축** 필요 |
| **RLS 정책** | 🟡 보통 | Postgres 표준 기능이라 SQL은 그대로. 단 `auth.uid()` 대체 필요 |
| **Edge Functions** | 🟢 쉬움 | Deno 코드 2개뿐. Node로 포팅 반나절 |
| **Realtime** | 🟡 보통 | WebSocket 서버 직접 구축 필요 |

**전체 이전 공수 예상: 1~2주.**

→ **감당 가능한 수준이다.** 지금 3~5주를 미리 쓰는 것보다 훨씬 낫다.
lock-in을 줄이려면 `src/api/`에 Supabase 호출을 격리해두면 된다 —
이미 그렇게 설계되어 있다([05-ARCHITECTURE.md](./05-ARCHITECTURE.md)).

## D. 전체 월 비용 시나리오

### MVP 출시 직후 (MAU ~50)

| **합계** | **약 2.2만원/월** |

### 성장기 (MAU 1,000)

| 항목 | 비용 |
|---|---|
| Supabase Pro | 3.5만원 |
| Vercel Pro (필요 시) | 2.8만원 |
| 도메인 | 2,000원 |
| AI (Opus 5, 월 15,000회) | **39만원** |
| **합계** | **약 45만원/월** |

### 🚨 핵심 인사이트

**인프라 비용은 거의 무시할 수준이고, AI 비용이 전체의 85% 이상이다.**

→ 비용 최적화 노력은 서버가 아니라 **AI 쪽에 집중**해야 한다:
1. 버튼 방식 (이미 결정) — 자동 대비 1/6
2. 모델 선택 — Sonnet 5로 바꾸면 39만원 → 16만원
3. `effort: 'low'` — 출력 토큰 최소화
4. 사진당 결과 캐시
5. 전역 월 예산 상한

상세는 [08-AI-PIPELINE.md](./08-AI-PIPELINE.md).

### 전원 무료 정책의 지속 가능성

MAU 1,000에서 월 45만원은 **개인 부담으로는 한계**다.
아래 중 하나를 미리 생각해둘 것:

| 옵션 | 내용 |
|---|---|
| A. 쿼터를 더 조인다 | 일 5회 → 일 3회. 비용 40% 감소 |
| B. 모델을 낮춘다 | Sonnet 5 또는 Haiku 4.5 |
| C. 부분 유료화 | 무료 일 3회 / 유료 무제한 (월 2,900원) |
| D. 전역 상한을 건다 | 월 예산 소진 시 다음 달까지 AI 중단 |

**MVP 단계에서는 D(전역 상한)만 걸고 시작하면 된다.** MAU 100까지는 월 4만원 이하다.
