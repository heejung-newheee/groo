# 12. 개발 로드맵

## MVP 6주 계획

각 주차는 **검증 기준(verify)**이 통과해야 완료다. "만들었다"가 아니라 "확인했다"가 기준.

---

### W1 — 기반

| 작업 | 검증 |
|---|---|
| 프로젝트 셋업 (Vite/TS/Tailwind/라우팅 셸) | `npm run dev` 정상, 3개 뷰포트 레이아웃 확인 |
| Supabase 프로젝트 생성 + 마이그레이션 적용 | 모든 테이블 생성, Advisors 경고 0건 |
| RLS 정책 전체 적용 | **다른 계정 토큰으로 내 데이터 조회 → 빈 배열** |
| Storage 버킷 + 정책 | 남의 폴더 업로드 시도 → 403 |
| 디자인 토큰 / 다크모드 | 라이트↔다크 전환 시 깨지는 곳 없음 |
| 타입 생성 파이프라인 | `npm run types:gen` 동작 |

> **침투 테스트 1~4번**([09-SECURITY.md](./09-SECURITY.md))을 여기서 통과시킨다.
> 나중으로 미루면 고치기 훨씬 비싸진다.

---

### W2 — 인증 + 식물 CRUD

| 작업 | 검증 |
|---|---|
| Google 로그인 | 가입 → 로그아웃 → 재로그인 성공 |
| Apple 로그인 | 동일 |
| **Kakao 로그인** | 동일 — ⚠️ 아래 참고 |
| 프로필 자동 생성 트리거 | 가입 시 `profiles` row 생성 확인 |
| 식물 등록 / 수정 / 목록 / 상세 | 등록 → 홈 그리드 즉시 반영 |
| 반응형 레이아웃 (모바일/태블릿/PC) | 3개 뷰포트에서 가로 스크롤 없음 |

> ⚠️ **Kakao는 Supabase 기본 제공 제공자가 아니다.**
> Kakao Developers에서 앱 등록 → REST API 키 발급 → Supabase에 커스텀 OAuth 설정.
> **반나절~1일 추가로 잡아둘 것.** Google/Apple 먼저 붙이고 Kakao를 마지막에.

---

### W3 — 사진 파이프라인 ★ 리스크 구간

| 작업 | 검증 |
|---|---|
| 사진 선택 UI (다중, 정렬) | 최대 5장, 드래그 정렬 동작 |
| **EXIF 추출** | [07-PHOTO-EXIF.md](./07-PHOTO-EXIF.md) 테스트 8케이스 전부 통과 |
| 리사이즈 + WebP 인코딩 | 12MB → 400KB 이하 |
| Orientation 보정 | 아이폰 세로 사진이 세로로 표시됨 |
| **GPS 미저장 확인** | `exiftool`로 업로드 파일에 GPS 없음 |
| Storage 업로드 + 실패 재시도 큐 | 네트워크 끊고 테스트 → 큐에 남음 |
| 일지 CRUD | 작성 → 타임라인 반영 |

> **이번 주가 MVP에서 가장 깨지기 쉬운 구간이다.** 여유를 두고 잡을 것.

---

### W4 — AI ★ 리스크 구간

| 작업 | 검증 |
|---|---|
| Edge Function `analyze-plant` | 로컬(`supabase functions serve`)에서 동작 |
| zod 구조화 출력 | `parsed_output` 항상 스키마 통과 |
| 쿼터 (일 5회) + 전역 상한 | 6번째 호출 → `skipped`, **API 호출 0회** |
| Realtime 수신 + 폴링 백업 | Realtime 끊어도 결과 도착 |
| AI 카드 UI (severity별) | 3단계 색상/아이콘 정확 |
| 면책 문구 + 피드백 버튼 | 항상 노출, 👍/👎 저장됨 |
| 실패 시 쿼터 미차감 | API 강제 실패 → 쿼터 그대로 |

> [08-AI-PIPELINE.md](./08-AI-PIPELINE.md) 테스트 8케이스 전부 통과.
> **모델 비교(Opus 5 vs Sonnet 5)를 이 주에 실행**해서 최종 결정한다.

## 리스크 관리

| 리스크 | 확률 | 영향 | 대응 |
|---|---|---|---|
| EXIF가 예상보다 더 안 나옴 | 높음 | 중 | 수동 입력 UX를 처음부터 1급 시민으로 |
| HEIC 처리 문제 | 중 | 중 | `accept` 제한으로 회피, 안내 메시지 |
| Kakao OAuth 설정 난항 | 중 | 소 | Google/Apple 먼저, Kakao는 W2 마지막 |
| AI 응답 품질 미달 | 중 | 큼 | W4에 모델 비교 + 프롬프트 반복 시간 확보 |
| AI 비용 초과 | 낮음 | 큼 | 전역 상한 + Console 지출 한도 |
| React Router v8 마이그레이션 이슈 | 낮음 | 중 | W1에 라우팅 셸 먼저 세워 조기 발견 |
